# Panduan Kata Kerja Operasional (KKO) Taksonomi Bloom & Kaidah ABCD

Dokumen ini memuat daftar Kata Kerja Operasional (KKO) Taksonomi Bloom Revisi (Anderson & Krathwohl) dan kaidah perumusan Capaian Pembelajaran (CPMK dan Sub-CPMK) berbasis standar akreditasi OBE (Outcome-Based Education).

---

## 1. Ranah Kognitif (Cognitive Domain - C1 s.d. C6)

Digunakan untuk merumuskan penguasaan pengetahuan, pemecahan masalah logis, dan kemampuan berpikir analitis-kreatif.

| Level Bloom | Definisi Kemampuan | Kata Kerja Operasional (KKO) Terukur | Contoh dalam Bidang Informatika |
| :--- | :--- | :--- | :--- |
| **C1: Remembering**<br>(Mengingat) | Mengingat kembali istilah, fakta, konsep, atau sintaks dari memori. | Mengidentifikasi, menyebutkan, mendefinisikan, mendaftar, mencocokkan, mengenali, mengulang. | *Mengidentifikasi* komponen arsitektur CPU Von Neumann. |
| **C2: Understanding**<br>(Memahami) | Memahami makna, menerjemahkan, menginterpretasi, dan mengelaborasi konsep. | Menjelaskan, mengklasifikasikan, membedakan, merangkum, menguraikan, menginterpolasi, mengilustrasikan. | *Menjelaskan* perbedaan antara proses dan thread dalam sistem operasi. |
| **C3: Applying**<br>(Menerapkan) | Menggunakan konsep, prosedur, atau algoritma untuk menyelesaikan masalah baru. | Menerapkan, mengimplementasikan, mengoperasikan, menghitung, mendemonstrasikan, memodifikasi, memecahkan. | *Mengimplementasikan* algoritma Dijkstra untuk pencarian rute terpendek dengan Python. |
| **C4: Analyzing**<br>(Menganalisis) | Memecah materi menjadi bagian-bagian logis dan menentukan hubungan antar komponen. | Menganalisis, membandingkan, mengkorelasikan, mendeteksi, mendiagramkan, membedah, mendiagnosis. | *Menganalisis* kompleksitas waktu dan ruang (*Big-O*) dari algoritma sorting. |
| **C5: Evaluating**<br>(Mengevaluasi) | Membuat penilaian/justifikasi berdasarkan kriteria, standar, dan bukti empiris. | Mengevaluasi, menilai, mengkritisi, memvalidasi, menjustifikasi, menguji kelayakan, membandingkan solusi. | *Mengevaluasi* kelemahan keamanan celah SQL Injection pada formulir autentikasi. |
| **C6: Creating**<br>(Mencipta) | Menyatukan elemen-elemen untuk membentuk struktur baru atau menghasilkan produk utuh. | Merancang, membangun, mengembangkan, mengintegrasikan, memformulasi, memproduksi, mengarsiteki. | *Merancang* dan *mengembangkan* sistem web berbasis microservices dengan Docker. |

## 2. Ranah Psikomotorik (Psychomotor Domain - P1 s.d. P5)

Digunakan untuk mengukur keterampilan teknis, penggunaan perangkat lunak/keras laboratorium, coding langsung, dan konfigurasi sistem.

| Level Bloom | Definisi Kemampuan | Kata Kerja Operasional (KKO) | Contoh dalam Praktikum Komputer |
| :--- | :--- | :--- | :--- |
| **P1: Meniru (Imitation)** | Mengamati dan meniru tindakan atau konfigurasi dasar instruktur. | Menyalin, mereplikasi, meniru, mereproduksi. | *Mereplikasi* konfigurasi routing statis pada router simulasi. |
| **P2: Manipulasi (Manipulation)** | Melakukan tindakan atau coding secara mandiri berdasarkan instruksi/panduan lab. | Menjalankan, memasang, memodifikasi, menyetel, mengkonfigurasi. | *Mengonfigurasi* server web Nginx dan database MySQL mandiri. |
| **P3: Presisi (Precision)** | Menunjukkan keterampilan secara akurat, mandiri, dan minim eror. | Menguji, mengkalibrasi, memvalidasi, memperbaiki bug (*debugging*). | *Melakukan debugging* kode program hingga seluruh unit test berstatus lulus. |
| **P4: Artikulasi (Articulation)** | Mengintegrasikan beberapa keterampilan menjadi satu alur kerja yang efisien. | Menggabungkan, mengkoordinasikan, mengadaptasikan, memadukan. | *Mengintegrasikan* frontend React dengan backend Laravel via REST API. |
| **P5: Naturalisasi (Naturalization)** | Melakukan keterampilan tingkat tinggi secara spontan, otomatis, dan mahir. | Merancang arsitektur terintegrasi, mengotomatisasi, mendesain *pipeline*. | *Membangun pipeline CI/CD* otomatis untuk deployment aplikasi cloud. |

## 3. Ranah Afektif (Affective Domain - A1 s.d. A5)

Digunakan untuk penilaian etika, kepatuhan hukum TIK, kepemimpinan tim, kerja sama, dan tanggung jawab profesional.

| Level Bloom | Definisi Sikap | Kata Kerja Operasional (KKO) | Contoh dalam Perkuliahan |
| :--- | :--- | :--- | :--- |
| **A1: Menerima (Receiving)** | Kesadaran dan kemauan mendengarkan ide/tata tertib. | Mengikuti, menyimak, memperhatikan, mematuhi. | *Mematuhi* etika akademik dan aturan orisinalitas kode tugas. |
| **A2: Menanggapi (Responding)** | Berpartisipasi aktif dalam diskusi atau kegiatan kelompok. | Menjawab, mengemukakan pendapat, berpartisipasi, menyajikan. | *Menyajikan* progres sprint proyek dan merespon masukan tim. |
| **A3: Menilai (Valuing)** | Menunjukkan komitmen terhadap nilai, etika profesi, atau kualitas kerja. | Menghargai, mendukung, mengapresiasi, berkomitmen. | *Menghargai* hak cipta perangkat lunak dan lisensi open-source. |
| **A4: Mengorganisasi (Organization)** | Memadukan berbagai nilai dan mengelola prioritas kerja secara sistematis. | Mengelola, mengkoordinasikan, merumuskan konsensus, menjadwalkan. | *Mengelola* pembagian peran dan jadwal sprint tim pengembang perangkat lunak. |
| **A5: Karakterisasi (Internalization)** | Menjadikan nilai etika dan profesionalisme sebagai karakter pribadi permanen. | Bertindak konsisten, bertakwa, berintegritas, menjunjung etika profesi. | *Bertindak profesional dan bertanggung jawab penuh* atas keamanan data pengguna. |

## 4. Kata Kerja yang DILARANG dalam Perumusan OBE

Hindari kata-kata yang bersifat **abstrak, ambigu, atau tidak dapat diukur secara langsung**:
- ❌ *Mengetahui* (Ganti dengan: *Menyebutkan*, *Mengidentifikasi*, *Menjelaskan*)
- ❌ *Memahami* (kecuali diikuti bukti operasional konkrit, misal: *Menjelaskan konsep X dengan diagram Y*)
- ❌ *Mempelajari* (Ini aktivitas belajar, bukan capaian hasil belajar)
- ❌ *Mendengarkan / Membaca* (Ini proses transfer informasi, bukan kompetensi)
- ❌ *Menyadari pentingnya* (Ganti dengan: *Mendemonstrasikan kepatuhan terhadap...*)

## 5. Kaidah Perumusan Capaian Pembelajaran Formula ABCD

Rumusan Sub-CPMK yang baik wajib memiliki 4 elemen utama:

```text
[Audience] + [Behavior] + [Condition] + [Degree]
```

1. **A - Audience (Sasaran Belajar)**: Mahasiswa peserta mata kuliah.
   *(Biasanya diseragamkan di awal: "Mahasiswa mampu...")*
2. **B - Behavior (Kemampuan yang Ditunjukkan)**: Menggunakan KKO Taksonomi Bloom yang jelas dan teramati.
   *(Contoh: merancang skema relasional, menulis kode SQL, mengoptimasi query)*
3. **C - Condition (Kondisi/Bahan Kajian/Alat)**: Konteks topik materi, metode, tools, atau studi kasus yang dihadapi.
   *(Contoh: menggunakan normalisasi 3NF dan perangkat lunak MySQL Workbench)*
4. **D - Degree (Tingkat Ketercapaian/Standar Mutu)**: Standar akurasi, efisiensi, kelengkapan, atau kualitas akhir.
   *(Contoh: tanpa anomali data dan memenuhi aturan integritas referensial)*

### Contoh Penerapan Nyata Formula ABCD:
> **Sub-CPMK 3**:
> *"Mahasiswa [A] mampu merancang skema basis data relasional [B] untuk studi kasus sistem informasi transaksi [C] yang dinormalisasi hingga bentuk 3NF secara benar dan bebas anomali [D] [C6, P3]."*
