## IV. DESKRIPSI SINGKAT & BAHAN KAJIAN

### Deskripsi Singkat Mata Kuliah
Mata kuliah Rekayasa Perangkat Lunak (RPL) membekali mahasiswa dengan pemahaman mendalam tentang prinsip, metodologi, dan teknik dalam rekayasa perangkat lunak modern berskala industri. Pokok bahasan mencakup siklus hidup pengembangan sistem (SDLC), metodologi Agile/Scrum, elisitasi dan spesifikasi kebutuhan (SRS standar IEEE), pemodelan berorientasi objek dengan UML, perancangan arsitektur perangkat lunak dengan prinsip SOLID dan Clean Architecture, teknik implementasi kolaboratif berbasis Git, penjaminan kualitas serta strategi pengujian Black Box dan White Box. Pembelajaran dirancang berpusat pada mahasiswa dengan pendekatan Project-Based Learning (PjBL) berkelompok untuk menghasilkan prototipe perangkat lunak yang solutif terhadap permasalahan nyata di masyarakat atau industri.

### Bahan Kajian (Materi Pembelajaran)
1. Pengantar Rekayasa Perangkat Lunak: Definisi software, software crisis, karakteristik software vs hardware, dan etika profesi rekayasa perangkat lunak.
2. Software Process & Metodologi SDLC: Linear/Waterfall, Prototyping, Incremental, RAD, dan Agile Methodologies (Scrum & Kanban).
3. Requirements Engineering: Elisitasi kebutuhan, analisis kebutuhan fungsional & non-fungsional, pemodelan use case, dan dokumentasi SRS standar IEEE 830 / ISO 29148.
4. Object-Oriented Analysis (OOA): Domain modeling, Use Case Specification, Activity Diagram, dan System Sequence Diagram.
5. Software Architecture & Design Principles: Architectural styles (Layered, Microservices, MVC), SOLID principles, dan dasar Design Patterns (GoF).
6. Object-Oriented Design (OOD): Detailed Class Diagram, State Machine Diagram, dan pemodelan persistensi data relasional/NoSQL.
7. User Interface Design & Interaction: Prinsip heuristik Nielsen, wireframing, dan prototipe interaktif.
8. Implementation & Team Collaboration: Version control dengan Git/GitHub, branching workflow, clean code conventions, dan code review.
9. Software Quality Assurance & Testing: Verifikasi vs validasi, White Box Testing (Basis Path, Cyclomatic Complexity), Black Box Testing (Equivalence Partitioning, Boundary Value Analysis), dan automated Unit Testing.
10. Software Maintenance, DevOps, & Evolution: Deployment dasar, CI/CD pipeline overview, refactoring, dan manajemen perubahan sistem.
